# Console-Based To-Do List Manager

A simple console-based To-Do List Manager built with Python. This project was created as a beginner Python project to practice fundamental programming concepts.

## Features

- Add new tasks
- View all tasks
- Remove tasks by task number
- Validate task number input
- Prevent invalid task selection
- Exit the application

## Concepts Practiced

- Variables
- Lists
- `if`, `elif`, and `else`
- `while` loops
- `for` loops
- Functions such as `len()`, `append()`, and `pop()`
- `enumerate()`
- User input with `input()`
- String methods such as `isdigit()`
- Type conversion with `int()`
- Basic input validation
